# Changelog

All notable changes to the OSEC project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-07-07

### Added
- Initial MVP release
- User authentication with phone/email and OTP verification
- Secure video streaming with screenshot protection
- Offline video playback in encrypted sandboxed storage
- MTN Mobile Money & Orange Money payment integration
- Trainer dashboard with course analytics
- Reviews and testimonials system
- Business tools hub (calculators, templates, planning)
- Bilingual interface (French/English)
- Push notification system
- CI/CD pipeline with GitHub Actions
- Docker containerization for backend services
- Comprehensive documentation (architecture, API, design system)
